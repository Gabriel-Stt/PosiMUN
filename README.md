# PosiMUN

Conference website for **PosiMUN**, a Model United Nations conference, served at [posimun.com](https://posimun.com).

I served as Vice Secretary-General for PosiMUN 2026, and this site is the delegate-facing hub for the conference: committee information, logistics, and reference materials for delegates before and during the event.

## What's here

- **Committee pages** — dedicated pages for each committee (UNSC, ECOSOC, UNHRC, UNOOSA, FISD, USHoR, and the Crisis Committee)
- **Logistics** — conference schedule, rules of procedure, and official delegate assignments
- **Background guides** — per-committee briefing PDFs delegates use to prepare position papers
- **Photo galleries** — coverage from the 2025 and 2026 conferences

## Stack

Static HTML/CSS, deployed via GitHub Pages with a custom domain.
